## Description

This technical note defines IUniformPhaseProvider as a minimal provider-side contract for isolating independent prime-phase generators in Riemann-Hypothesis-oriented prime-wave experiments. The specification separates rational independence, finite-torus equidistribution, and fixed-scale mean-square cancellation from analytic continuation, explicit formulae, zero correlations, and RH-equivalent error estimates.

The document is a contract specification, not a proof of the Riemann Hypothesis. It is intended to support future Lean formalization, C# simulation, and conditional proof-interface experiments by making the Provider responsibility explicit and fail-closed.

The English manuscript is the canonical version. The Japanese manuscript is included as a companion translation.
